================================================================================
  GitHub 仓库重建 · 操作步骤（删旧建新 + 推送）
================================================================================

本地已全部准备完毕，你只需三步。

--------------------------------------------------------------------------------
【第 1 步】删除 GitHub 上的旧仓库
--------------------------------------------------------------------------------
1. 打开：https://github.com/Yoyzhao/WebSR/settings
2. 滚到页面最下方 **Danger Zone** → 红色 **Delete this repository**
3. 按提示输入完整仓库名确认：`Yoyzhao/WebSR`

   ⚠️ 此操作不可撤销。但**不用担心**：本地已保留全部内容，且有完整备份
      （见下方「出错了怎么办」）。

--------------------------------------------------------------------------------
【第 2 步】新建同名空仓库
--------------------------------------------------------------------------------
1. 打开：https://github.com/new
2. Owner 选 `Yoyzhao`，仓库名填 `WebSR`
3. **重要：不要勾选** "Add a README file" / "Add .gitignore" / "Choose a license"
   —— 勾了会导致远端有独立提交，与本地历史冲突。

--------------------------------------------------------------------------------
【第 3 步】推送
--------------------------------------------------------------------------------
在项目根目录（E:\Desktop\Workspace2\WorkBuddySpace\WebSR）打开 Git Bash，
把下面命令里的 <你的GitHub用户名> 和 <你的PersonalAccessToken> 替换成实际值：

  cd "E:/Desktop/Workspace2/WorkBuddySpace/WebSR"

  git -c credential.helper= \
      -c http.proxy=socks5://127.0.0.1:10089 \
      push https://<用户名>:<Token>@github.com/Yoyzhao/WebSR.git main

说明：
  - `credential.helper=` 必须带上 —— 本机 git 的凭据助手会崩（已知问题）。
  - Token 用 GitHub 网页生成：Settings → Developer settings → Personal access
    tokens → Generate new token (classic)，勾 `repo` 权限即可。**只在你自己的
    命令行里用，别提交进仓库。**
  - 推送完成后 token 建议撤销（revoke），因为它只用于这一次。

--------------------------------------------------------------------------------
【验证成功】
--------------------------------------------------------------------------------
推送后检查远端体积，应为 **约 2 MB**（不再是 593 MB）：

  git -c credential.helper= -c http.proxy=socks5://127.0.0.1:10089 \
      ls-remote https://<用户名>:<Token>@github.com/Yoyzhao/WebSR.git

再去网页确认：仓库首页不再有模型权重文件，提交历史显示 30 个提交。

--------------------------------------------------------------------------------
【出错了怎么办 · 退路】
--------------------------------------------------------------------------------
完整历史已打包成 bundle（重写前的原始状态，含 593MB 垃圾，用于兜底）：

  E:\Desktop\Workspace2\_git-backup\WebSR-full-20261011-0344.bundle

如需恢复：

  git clone <bundle路径> WebSR-restored
  cd WebSR-restored && git checkout backup-before-rewrite-20261011

提示：打在这个 bundle 上的 tag 名叫 backup-before-rewrite-20261011，
      它指向的是**重写前**的原始历史（这就是为什么它单独存在 bundle 里）。
