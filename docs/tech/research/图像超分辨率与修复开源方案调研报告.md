# 图像超分辨率 / 修复（Image Super-Resolution & Restoration）开源方案调研报告

> 调研对象：Real-ESRGAN 及其之后更具先进性、仍在活跃迭代的开源项目
> 报告日期：2026-09-29
> 说明：本报告基于各项目官方仓库、论文与官方新闻稿核实撰写；star 数、迭代状态为调研时点快照，使用前建议再核对一次。

---

## 0. 结论速览（TL;DR）

1. **Real-ESRGAN 并未"过时"，但也确实"停更了"**：它把 ESRGAN 从"论文算法"变成了"能用的工具"，其工程地位至今没有项目能完全取代（轻量、跨平台、ncnn-Vulkan 生态极广）。但核心仓库自 2022 年起基本停止演进，且它属于 **GAN/感知向** 路线，在极端退化、大倍率、文字与人脸场景下存在明确天花板。

2. **技术已经换代了两轮**：`CNN/GAN（2018–2022）` → `Transformer 保真向（2021–2024）` → `扩散生成向（2023–2024）` → **`单步扩散 / 蒸馏（2024–2026，当前主流）`**。

3. **当前"最先进且开源"的答案不是单一项目，而是三条并行的路线**：

   | 你的目标 | 首选开源方案 | 一句话理由 |
   |---|---|---|
   | 要**最低成本、最大兼容性**跑通 | **Real-ESRGAN + ncnn-Vulkan（Upscayl / chaiNNer）** | 仍在被广泛使用，GPU 要求最低 |
   | 要**当前综合最优画质 + 可接受的推理成本** | **OSEDiff / InvSR / HYPIR / TSD-SR（单步扩散系）** | 一步推理即达到多步扩散的画质 |
   | 要**画质天花板、有 24GB 显存、能等** | **SUPIR** | 扩散 + 多模态 LLM 引导，仍是开源画质上限 |
   | 要**人脸修复** | **CodeFormer（可控保真度）/ GFPGAN** | w 权重可调"像不像 vs 好不好看" |
   | 要**视频超分** | **SeedVR2（ComfyUI）/ FlashVSR** | 前者成熟易用，后者是 2026 年实时化突破 |

4. **一个必须知道的事实**：扩散类方案"恢复"出的细节是**模型生成的合理内容**，不是原始信息的还原。用于取证、医疗、档案等场景时，这是不可接受的（详见第 6 节）。

## 1. Real-ESRGAN 项目剖析

### 1.1 基本信息

| 项目 | 内容 |
|---|---|
| 仓库 | https://github.com/xinntao/Real-ESRGAN |
| 团队 | 腾讯 ARC Lab（王鑫涛 Xintao Wang 主导）+ 中科院深圳先进院、香港中文大学 |
| 论文 | *Real-ESRGAN: Training Real-World Blind Super-Resolution with Pure Synthetic Data*（arXiv 2107.10833） |
| 定位 | **Practical Algorithms for General Image/Video Restoration**（面向实用的通用图像/视频复原） |
| 代码许可 | BSD-3-Clause（允许商用，模型权重另见各模型页说明） |
| 热度 | 约 3 万+ star，是超分领域 star 最高的项目之一 |
| 维护状态 | ⚠️ **基本停更**：最新版本 v0.2.9（2022.09），核心代码与 README 自 2022 年后无实质更新 |
| 关键衍生 | Real-ESRGAN-ncnn-vulkan（官方 C++/Vulkan 实现）、Upscayl、chaiNNer、Video2X、Paper2GUI |

### 1.2 核心思想：为什么它是"实用化"的转折点

在它之前，SR 模型普遍用**理想的 bicubic 下采样**做退化建模，训练数据"太干净"，一遇到真实世界的模糊、噪点、JPEG 压缩块就崩。Real-ESRGAN 的核心贡献是**用"纯合成数据"模拟真实退化**：

- **高阶退化建模（High-order Degradation）**：把 `模糊 → 缩放 → 加噪 → JPEG 压缩` 这条流程**重复执行两次**，并用 shuffle 打乱顺序，从而覆盖真实照片里那些"复合型、说不清来源"的劣化。
- **用合成数据替代真实配对数据**：不再费力去采集"低清-高清"配对样本，训练成本和数据门槛大幅下降。
- **继承 ESRGAN 的生成器 + 相对判别器（RaGAN）**：以对抗训练换取"看起来真实"的纹理，而不是一味追求 PSNR。

一句话：**它把"退化建模"当成核心问题来解决，而不是把网络堆得更深。**

### 1.3 网络结构与损失

- **生成器**：RRDBNet（Residual-in-Residual Dense Block），`x4plus` 约 16.7M 参数；动漫专用 `anime_6B` 用 6 个 block 大幅瘦身。
- **判别器**：U-Net 结构 + 谱归一化（Spectral Normalization）。
- **损失**：L1（像素/保真）+ 感知损失（VGG 特征）+ GAN 损失，典型的三件套。
- **训练框架**：基于 BasicSR。

### 1.4 模型家族与能力矩阵

| 模型 | 用途 | 特点 |
|---|---|---|
| `RealESRGAN_x4plus` | 通用照片 4x | 旗舰，通用性最好 |
| `RealESRGAN_x2plus` | 通用照片 2x | 轻度放大，更保守 |
| `RealESRGAN_x4plus_anime_6B` | 动漫/插画 4x | 体积小、线条干净，与 waifu2x 对比见官方 `anime_model.md` |
| `realesr-general-x4v3` | 通用小模型 | 极小体积，支持 `-dn`（denoise strength）在"去噪"与"保细节"之间调节，避免过度平滑 |
| `realesr-animevideov3` | 动漫**视频** x2/x3/x4 | 视频专用，时序一致性与速度优化 |
| `RealESRNet` | 去噪、求稳 | 去掉 GAN，输出更平滑（少幻觉） |

**推理功能**：
- `--tile` 分块推理 —— 大图 / 低显存的关键开关
- 支持 **alpha 通道、灰度图、16-bit 图**
- `--outscale` 任意倍率（真实做法是 4x 后接 Lanczos 重采样，**不是真的任意倍率模型**）
- `--face_enhance` 直接集成 **GFPGAN** 做人脸二次增强
- 支持视频（逐帧）与自训练/微调（见 Training.md）

### 1.5 生态价值（它真正的护城河）

Real-ESRGAN 的生命力已经转移到**周边实现**上：

- **Real-ESRGAN-ncnn-vulkan**（官方）：C++ 实现，**不需要 CUDA**，Vulkan GPU / CPU / Apple Silicon 都能跑，是 Windows 便携包的基础。
- **Upscayl**：最流行的开源 GUI 封装（AGPL-3.0），内置 Real-ESRGAN、Real-CUGAN 等模型，需要 Vulkan 兼容 GPU。
- **chaiNNer**：节点式图像处理 GUI，可混排 Real-ESRGAN、SwinIR、HAT 等模型，支持 TensorRT/BF16 加速，适合搭复杂流水线。
- **Video2X / Waifu2x-Extension-GUI / Paper2GUI**：视频与批量场景的封装。

### 1.6 客观评价：它的局限（也正是后来者要解决的问题）

| 局限 | 具体表现 |
|---|---|
| **生成能力有限** | GAN 的"幻觉"幅度远小于扩散模型，极端退化（严重模糊、严重压缩）下恢复不出细节，只能"变干净" |
| **人脸是短板** | 必须外挂 GFPGAN / CodeFormer，否则会得到"塑料脸" |
| **无语义控制** | 不能像扩散模型那样用文本 prompt 引导（"这是老照片，胶片颗粒感"），也不能按偏好在"保真/美化"之间连续调节 |
| **文字 / 文档薄弱** | 屏摄、截图、招牌上的文字容易被糊成伪字形 |
| **大倍率不稳定** | 一次性 8x / 16x 基本必崩，只能分次 4x |
| **项目停更** | 没有官方新模型、新架构；社区依赖第三方封装维持可用性 |
| **开源方向被"下一代"覆盖** | 同一批作者（董超团队 / XPixelGroup）已经用 SUPIR、DiffBIR、HYPIR 把路线推进到扩散时代 |

**一句话总结：Real-ESRGAN 是"低门槛、够用、生态最广"的基线方案；它不是"最先进"，但仍是"最省事"。**

## 2. 技术演进脉络：四个时代

```
【第一时代 · CNN / GAN 感知向】2018 – 2022
  SRCNN → SRResNet → ESRGAN → BSRGAN → Real-ESRGAN
  关键词：对抗训练、退化建模、速度快、能商用
  代表现役：Real-ESRGAN、Real-CUGAN、waifu2x

        ↓ 瓶颈：细节靠"编"，PSNR 不高，无法语义控制

【第二时代 · Transformer 保真向】2021 – 2024
  SwinIR → HAT → DAT → DRCT
  关键词：注意力机制、PSNR/SSIM 刷榜、像素级准确
  适用：需要"准确还原"而非"好看"的场景

        ↓ 瓶颈：同样是"映射"，缺乏生成新细节的能力

【第三时代 · 扩散生成向】2023 – 2025
  StableSR → DiffBIR → SeeSR → ResShift → CCSR → SUPIR
  关键词：借用 Stable Diffusion 先验、画质天花板、可 prompt 控制
  代价：几十步去噪，一张图几十秒到几分钟，显存 16–24GB+

        ↓ 瓶颈：太慢、太贵、结果有随机性

【第四时代 · 单步扩散 / 蒸馏】2024 – 2026（当前主流）
  OSEDiff → InvSR → TSD-SR → D3SR → AdcSR → PiSA-SR → HYPIR → FlashVSR
  关键词：1 步推理达到多步扩散画质、速度提升 10~100 倍
  这是当前"最先进 + 可工程化"的交集区
```

## 3. 更先进的开源项目详表

### 3.1 单步扩散 / 蒸馏系 —— 当前综合最优选择 ⭐ 重点推荐

这一族把"扩散模型几十步去噪"压缩到 1 步，是 2024 年之后最重要的工程突破。

| 项目 | 时间 / 会议 | 核心方法 | 关键指标 | 许可 | 说明 |
|---|---|---|---|---|---|
| **OSEDiff** | NeurIPS 2024 | 直接把低清图当扩散起点（不加随机噪声）+ LoRA 微调 + 变分分数蒸馏（VSD） | A100 上 512×512 **约 0.1 秒/张**；比 StableSR 快 100 倍以上 | **Apache-2.0** | 参数增量极小；**已被 OPPO Find X8 系列产品化落地**，工程成熟度高 |
| **InvSR** | CVPR 2025 | 扩散反演 + "部分噪声预测"，构造中间状态作为采样起点 | **支持 1~5 步任意选择**；单步即可对标多步 SOTA | 学术开源 | 灵活度高，1k→4k 大图建议开启 `--chopping_size 256` |
| **HYPIR** | 2025.07（SIAT / XPixelGroup） | 放弃迭代扩散，改用**预训练扩散模型初始化 + 单步对抗生成**（LoRA） | 单卡 **1.7 秒 / 1024×1024**；支持 **8K** 级细节；**文字保真**强；比 SUPIR 快数十倍且更稳定可控 | 学术开源（开源版基于 SD-2.1） | 董超团队出品，论文级"范式简化"；官方还有商业版 suppixel |
| **TSD-SR** | 2025 | Target Score Distillation + 分布感知采样 | **比 SeeSR 快约 40 倍**，多数指标最优 | 学术开源 | one-step Real-ISR 的代表作之一 |
| **D³SR** | 2024 | 大规模**扩散判别器**替代"教师模型蒸馏" | 比同类单步法**快 ≥3 倍**，参数**少 ≥30%** | 学术开源 | 突破了"受限于教师模型能力"的问题 |
| **AdcSR** | CVPR 2025 | 对抗式扩散压缩框架 | **比 OSEDiff 再快 9.3 倍** | 学术开源 | 速度路线的激进代表 |
| **PiSA-SR** | CVPR 2025 | 可调扩散网络 | 面向用户偏好调节 | 学术开源 | 让使用者自己控制"保真/美化" |
| **CCSR / CCSRv2** | CVPR 2024 / TIP 2026 | 可控条件超分 | v2 支持 **1~15 步任意** | 学术开源 | 步数与质量可连续折中 |
| **TVT** | ICCV 2025 | 重训 SD2.1 的 VAE、保留 UNet | 更精细的 Real-ISR | 学术开源 | 偏底层改进 |
| **VOSR** | CVPR 2026 | 仅视觉（vision-only）的原生生成框架 | 最新方向 | 待开源 | 值得跟踪 |

> **实践建议**：若要在自己的产品/工具里替换 Real-ESRGAN，**OSEDiff（Apache-2.0，已产品化）** 或 **HYPIR（速度与文字保真突出）** 是风险最低的两个起点。

### 3.2 扩散多步系 —— 画质天花板

| 项目 | 时间 | 方法 | 资源需求 | 许可 |
|---|---|---|---|---|
| **SUPIR** | CVPR 2024 | **SDXL 骨干 + LLaVA 多模态引导**（自动生成修复 prompt）+ ZeroSFT 保几何一致 | **推荐 24GB 显存**（16GB 勉强）；单图耗时数十秒~分钟级 | ⚠️ 自定义许可，**商用前务必核实权重条款** |
| **DiffBIR** | ECCV 2024 | **两阶段**：SwinIR 先去退化 → IRControlNet 扩散精修；v2.1 支持 tiling | 支持低显存分块 | 学术开源 |
| **StableSR** | IJCV 2024 | 微调 SD + 小型自编码器（TAESD 思路） | **128→512 只需约 8.9GB 显存** | NTU S-Lab License 1.0 |
| **SeeSR** | CVPR 2024 | 语义感知扩散 SR，注入语义提示提升目标级保真 | 显存较高 | 学术开源 |
| **ResShift** | NeurIPS 2023 | 残差位移，**把扩散步数压到 15~20 步** | 中等 | 学术开源 |

**SUPIR 的定位**：它仍是目前**开源画质上限**——但代价是 24GB 显存、几十秒到几分钟的单图耗时，以及"生成内容较多、可能偏离原始内容"的保真度风险。适合"宁要好看、不要慢"的场景（老照片、海报、概念图）。

### 3.3 Transformer 保真向 —— 要"准确"不要"好看"

| 项目 | 时间 | 参数量 | 相对表现 | 许可 |
|---|---|---|---|---|
| **SwinIR** | ICCV 2021 | 11.9M | 经典/轻量/真实世界 SR、去噪、JPEG 伪影去除，全面 SOTA baseline | Apache-2.0 |
| **HAT** | CVPR 2023 + TPAMI 2023 | 20.8M（HAT-S 9.6M） | 混合注意力，SRx4 比 SwinIR 高 0.12dB；另提供 **Real_HAT_GAN_SRx4_sharper** 用于真实场景感知增强 | Apache-2.0 |
| **DAT** | ICCV 2023 | — | 双轴聚合注意力，效率与效果折中 | 学术开源 |
| **DRCT** | CVPRW 2024 | — | 密集残差连接 Transformer，缓解 SwinIR 信息流损失 | 学术开源 |
| **BSRGAN** | ICCV 2021 | — | 第一个"实用退化模型"，Real-ESRGAN 的思想前辈 | 学术开源 |

**选择逻辑**：如果你的下游任务对**像素准确度**敏感（医学影像、遥感、工业检测、测量），Transformer 保真向**优于**扩散生成向——因为扩散会"编"出不存在的东西。

### 3.4 人脸修复专用

| 项目 | 时间 | 方法 | 特点 | 许可 |
|---|---|---|---|---|
| **CodeFormer** | NeurIPS 2022 | 码本查找 Transformer（Codebook Lookup） | ⭐ **`w` 参数（0~1）可调**：小 w 更"好看"、大 w 更"像本人"；还支持人脸**上色**与**修补**、视频；社区集成最广（SD WebUI、ComfyUI、chaiNNer） | NTU S-Lab License 1.0 |
| **GFPGAN** | CVPR 2021 | StyleGAN2 先验 + 退化感知 | 与 Real-ESRGAN 同团队，几乎与 Real-ESRGAN 绑定成标准管线；v1.3/v1.4 | Apache-2.0 |
| **RestoreFormer / ++** | CVPR 2022 | 多尺度交叉注意力 | 细节更强，偏学术 | 学术开源 |
| **GPEN** | CVPR 2021 | GAN 先验嵌入网络 | 重度退化下输出更柔和，是 GFPGAN 过锐时的替代 | 学术开源 |
| **DifFace** | 2023 | 扩散先验做人脸修复 | 用于 DiffBIR 的 face 分支 | 学术开源 |

**标准两阶段管线（社区事实标准）**：
```
整图 Real-ESRGAN / SwinIR 放大  →  人脸区域再交给 CodeFormer 或 GFPGAN 精修  →  融合回背景
```

### 3.5 二次元 / 动漫专用

| 项目 | 来源 | 特点 |
|---|---|---|
| **Real-CUGAN** | 哔哩哔哩 | 动漫线条保留最好；支持 **降噪等级 -1~3** × 放大 2/3/4 倍；有 ncnn-Vulkan 版 |

### 3.6 视频超分 —— 2025–2026 增长最快的方向

| 项目 | 时间 | 关键指标 | 说明 |
|---|---|---|---|
| **SeedVR2** | 2025（字节跳动） | 3B / 7B 模型；3B 版也要约 18GB 显存；支持 BlockSwap + GGUF 量化降到 8GB | 目前**最成熟**的视频超分开源方案，官方 ComfyUI 节点 + 独立 CLI + 多 GPU；时序一致性需 batch_size ≥ 5 |

| **DOVE** | 2025 | 一步扩散视频超分 | FlashVSR 的直接对比基线 |
| **Video2X** | 社区 | 集成 Real-ESRGAN / Real-CUGAN / Anime4K / RIFE（补帧） | 一站式旧视频修复工具链 |
| **Real-ESRGAN 视频能力** | 2022 | 逐帧 + animevideov3 | 老方案，适合动漫，真人视频效果一般 |

### 3.7 工具链 / 前端（决定"能不能真用起来"）

| 工具 | 类型 | 许可 | 说明 |
|---|---|---|---|
| **Upscayl** | 桌面 GUI | **AGPL-3.0** | 最易上手；内置 7 个 ncnn 模型（其中 Remacri / Ultramix / Ultrasharp 标注**非商用**）；需 Vulkan 1.0+ 兼容 GPU（官方兼容表已确认 Intel HD 620 / Iris 集显可用）；不能去虚焦 |
| **chaiNNer** | 节点式 GUI | 开源（以仓库为准） | 可混排多种 SR 模型、支持 TensorRT/BF16 加速、跨模型搭流水线，进阶首选 |
| **ComfyUI** | 节点式生成平台 | GPL 系 | 扩散类模型（SUPIR / SeedVR2 / OSEDiff 系）事实上的主战场 |
| **ncnn-Vulkan 系列** | 命令行 + 便携包 | 各项目许可 | Real-ESRGAN / Real-CUGAN / waifu2x 均有，**CPU 也能跑** |
| **Paper2GUI** | 一站式 GUI 集合 | 开源 | 把 RealESRGAN / RealCUGAN / Waifu2x / RealSR 打包成图形工具 |

## 4. 横向对比（决策表）

## 5. 选型建议（按场景直接抄）

| 你的场景 | 建议组合 |
|---|---|
| **个人电脑、偶尔处理照片，无独立显卡** | Real-ESRGAN-ncnn-vulkan 或 Upscayl（需 Vulkan GPU）；CPU 则用 ncnn 版 |
| **批量处理海量照片，追求性价比** | OSEDiff（Apache-2.0，快且可商用）批量脚本 |
| **老照片修复（人物 + 划痕 + 褪色）** | Real-ESRGAN/OSEDiff 整图放大 **+ CodeFormer 人脸精修**；有条件上 SUPIR |
| **动漫 / 插画 / 番剧截帧** | Real-CUGAN 或 Real-ESRGAN anime_6B；视频用 realesr-animevideov3 |
| **视频超分（真人 / 长视频）** | SeedVR2（ComfyUI 节点，8GB 起可量化跑）；追求实时再看 FlashVSR |
| **文档、截图、招牌文字** | **HYPIR**（文字保真突出）；避免纯 GAN 方案 |
| **医学 / 遥感 / 工业检测（要求像素准确）** | SwinIR / HAT 等 Transformer 保真向，**不要用扩散生成类** |
| **在产品里长期维护的超分模块** | OSEDiff（许可宽松 + 已被手机厂商产品化）为基线，持续跟踪 HYPIR / InvSR |
| **要搭复杂可复用流水线** | chaiNNer（节点式）+ ComfyUI（扩散模型） |

## 6. 风险与注意事项 ⚠️

1. **"修复"≠"还原"**：扩散类与 GAN 类都会**生成不存在的内容**。SUPIR、OSEDiff 等能"恢复"出清晰的皮肤纹理、睫毛、字形，但这些细节是模型基于先验**推测**的。**用于司法取证、医疗影像、新闻纪实、档案凭证等场景时，存在严重的真实性问题**，必须慎用或仅在人工复核后使用。

2. **文化 / 历史资料的合规底线**：修复历史照片、影像时，不应改变人物身份特征、服饰、文字内容等事实性信息。修复结果应明确标注"AI 生成/推测"，避免误导。

3. **许可证是商用红线**（最容易踩坑）：
   - ✅ **宽松**：Real-ESRGAN（BSD-3）、GFPGAN / SwinIR / HAT（Apache-2.0）、OSEDiff（Apache-2.0）
   - ⚠️ **需谨慎**：**SUPIR**（自定义许可，权重条款需逐字核对，偏非商用）；CodeFormer / StableSR（**NTU S-Lab License 1.0**，非标准商业许可）；Upscayl（**AGPL-3.0**，衍生服务需注意开源义务）
   - 各模型**代码许可与权重许可可能不同**，商用前请分别核实。

4. **技术边界**：不要把 1MP 的图指望成 8K 大片。信息论上限摆在那里——上采样能恢复的，只有"模型认为应该长这样"的部分。**source 质量永远比模型选择更重要。**

5. **一次放大倍率别贪**：多数模型的单次最佳倍率是 2x 或 4x；直接上 8x/16x 在多数测试中失败率很高，正确做法是**分两轮 4x** 并检查中间结果。

6. **警惕信息质量**：中文互联网上关于"2026 年超分工具排行"的文章大量由 SEO 站点生成，其版本号、发布年份、许可信息**经常是编造的**（例如把 2023 年的 StableSR 说成"2026 年初以 Apache 2.0 发布"）。做技术选型请**以 GitHub 仓库与论文为准**。
