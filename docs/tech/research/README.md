## ⚠️ 使用这些文档时最重要的两条约定

### 1. 机制硬编码，数值运行时求

| 类别 | 例子 | 能否进产品 |
|---|---|---|
| **机制 / 因果** | EP 会静默回退；`arena_extend_strategy` 默认值可致数量级劣化；ORT + OpenVINO EP 是负收益；OpenVINO GPU 插件会误枚举非 Intel 卡；WDDM 拿不到按进程显存；无 fp16 单元的 CPU 上 fp16 更慢 | ✅ 固化进代码作为防御 |
| **数值 / 量级** | 「10.3x」「1.64x」「20.4 s」「5.5 GB」 | ❌ 仅作同机对照与量级校验 |
| **绝对阈值** | 可用显存 7.4 GB；tile 384 是甜点 | ❌ 仅作自标定的起步点与合理区间 |

**本机（i5-12400F 无核显 + RTX 3050 OEM 8G）是开发机，不代表用户环境。** 产品里 tile / 精度 / EP / 并发度必须由运行时探测 + 首启自标定得出。
