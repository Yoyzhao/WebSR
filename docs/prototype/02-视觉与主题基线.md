# 02 · 视觉与主题基线

> 步骤 5A 产出 ｜ 设计稿：Ardot「WebSR 前端原型 · S1」 ｜ 最后更新：2026-09-30

> 本文件是 5C 落地时的**唯一视觉事实源**。CSS 变量见 [`tokens.css`](tokens.css)。

---

## 1. 设计方向

**一句话**：暗房里的工作台——深炭灰底、克制的控件、让图像本身成为唯一的主角。

三条约束（源自 PRD §6.4）：

1. **控件克制**：全站只有一个强调色，没有渐变装饰、没有插画、没有阴影堆叠。卡片靠 1px 描边和背景层级区分，不靠投影。
2. **图片区域不叠浮层**：对比视图的标注一律放在画布下方，不覆盖在图像上。
3. **密度偏高**：这是工具，不是营销页。基准字号 12px，表格行高 48，信息密度优先。

## 2. 颜色 token

### 2.1 背景层级（4 层）

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `bg-app` | `#0F0E0E` | `#F7F6F4` | 应用底：中栏、独立页背景 |
| `bg-panel` | `#1A1919` | `#FFFFFF` | 面板：顶栏、左栏、右栏、卡片 |
| `bg-elevated` | `#242323` | `#FFFFFF` | 抬升面：输入框、徽标、内嵌提示、次级按钮 |
| `bg-hover` | `#2A2929` | `#EDECEA` | 悬停态、选中态、进度条轨道 |

**用层级而非分割线建立层次**：一个卡片 = `bg-panel` + 1px `border-subtle`；卡片内的次级容器 = `bg-elevated`，没有描边。深浅相差一级即可分辨，不需要更重的视觉手段。

### 2.2 边框

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `border-subtle` | `#2E2D2D` | `#E2E0DD` | 卡片描边、栏间分隔 |
| `border-strong` | `#3D3C3C` | `#CFCCC8` | 拖拽区边框、聚焦态 |

### 2.3 文字（3 级）

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `text-primary` | `#F2F2F2` | `#1A1918` | 标题、关键数值、文件名、输入值 |
| `text-secondary` | `#A8A8A8` | `#5C5A58` | 正文、标签、表头、按钮文字 |
| `text-tertiary` | `#8C8C8C` | `#757370` | 辅助说明、占位符、次要元信息 |

> ⚠️ **`text-tertiary` 的取值经过无障碍修正**。初版取 `#6E6D6D`，在 `bg-panel` 上对比度仅 **3.44:1**，低于 WCAG AA 对正文（<18.66px）要求的 4.5:1。现取 `#8C8C8C`（5.2:1）。浅色版同理由 `#8F8C87`（3.23:1）修正为 `#757370`（4.54:1）。
>
> 由此带来的副作用是：三级文字与二级文字的色差变小，**层级区分需依赖字号与位置，而非仅靠颜色**——这本身也更符合无障碍要求。

### 2.4 强调色与语义色

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `primary` | `#0078D4` | `#0067C0` | 主按钮底色（全站唯一强调色） |
| `primary-hover` | `#1A8AE0` | `#0078D4` | 主按钮悬停 |
| `link` | `#60CDFF` | `#0067C0` | 进行中状态、可点击文字、激活强调 |
| `success` | `#7DD9A6` | `#107C41` | 已完成、可运行、EP 验证通过 |
| `warning` | `#E8C268` | `#9A6700` | 降级、保底档、条件支持、未标定 |
| `error` | `#E07866` | `#C42B1C` | 失败、不可用、删除操作 |

**语义映射规则（不可反直觉使用）**

| 状态 | 颜色 | 出现位置 |
|---|---|---|
| 进行中 / 运行中 | `link` | 任务状态文字、进度数字、"正在推理 N / M 块" |
| 已完成 / 可运行 / 已生效 | `success` | 任务状态、模型可用性、显存充足、EP 验证通过 |
| 降级完成 / 保底档 / 条件支持 | `warning` | 任务状态、保底档提示、自动档接管标记、ncnn 条件支持 |
| 失败 / 不可用 / 删除 | `error` | 任务状态、模型置灰原因、删除按钮文字 |
| 已取消 / 未使用 / 禁用 | `text-tertiary` | 已取消任务、回退项 EP、禁用按钮 |

| 组合 | 对比度 | 判定 |
|---|---|---|

| `text-secondary` / `bg-panel`（深） | 7.4 : 1 | ✅ AAA |
| `text-tertiary` / `bg-panel`（深） | 5.2 : 1 | ✅ AA |
| `text-primary` / `bg-panel`（浅） | 17.4 : 1 | ✅ AAA |
| `text-secondary` / `bg-panel`（浅） | 6.7 : 1 | ✅ AAA |
| `text-tertiary` / `bg-panel`（浅） | 4.8 : 1 | ✅ AA |
| 白字 / `primary`（深） | 4.5 : 1 | ✅ AA |
| 白字 / `primary`（浅） | 5.8 : 1 | ✅ AA |
| `success` / `bg-panel`（深） | 11.5 : 1 | ✅ AAA |
| `warning` / `bg-panel`（深） | 10.7 : 1 | ✅ AAA |
| `error` / `bg-panel`（深） | 5.9 : 1 | ✅ AA |
| 图标 `#8A8A8A` / `bg-panel`（深） | 4.9 : 1 | ✅ |

### 2.6 配色比例（60-30-10）

- **60%** —— `bg-app` + `bg-panel`：大面积底色
- **30%** —— `bg-elevated` + `bg-hover`：结构性次级面（输入框、徽标、表头、进度轨道）
- **10%** —— `primary` 与四类语义色：主按钮、状态文字、关键数值

**同时出现的高强调元素不超过 2 个**。例如任务中心里，若"失败"行用红色状态文字，其操作按钮就只用中性色（仅"降低倍数重试"保持 primary，因为它是该行唯一可推进的出口）。

## 3. 字号层级

> **2026-10-08 整体上调一档**（补偿 2K 分辨率下的像素密度，用户反馈默认偏小）。
> 采用**重新编号**而非「改值不改名」：token 名始终等于像素值。
> 映射关系：`10/11/12/13/15/18/24` → `11/12/13/14/16/20/26`。
> ⚠️ 组件内一律引用 token，禁止硬编码 `font-size` —— 5C 闭环验证时发现
> 全项目曾有 111 处硬编码字号，导致 token 形同虚设，已一并收敛。

| Token | 值 | 字重 | 用途 |
|---|---|---|---|
| `font-size-11` | 11 | Regular | 格式徽标（ONNX / SAFETENSORS）、条件支持提示 |
| `font-size-12` | 12 | Regular | 表格单元格、元信息、图例、辅助说明 |
| `font-size-13` | 13 | Regular / Medium | 主要正文、按钮、表单标签、Tab |
| `font-size-14` | 14 | Medium / SemiBold | 面板标题、卡片标题、输入值、顶部导航强调 |
| `font-size-16` | 16 | Regular / SemiBold | 品牌名、空态主文案、档位卡标题 |
| `font-size-20` | 20 | SemiBold | 独立页标题 |
| `font-size-26` | 26 | Bold | 档位大徽标（全站唯一的大字号，无营销级标题） |

**行高**：紧排 1.3 ｜ 正文 1.45 ｜ 长段说明 1.55

**随字阶同步上调的布局尺寸**（字号 +1 档后，原行高与控件高度会显得拥挤）：
顶栏 `56 → 60` ｜ 表格行 `48 → 52` ｜ 输入框 `36 → 40` ｜ 图标按钮 `32 → 36`。
面板宽度（320 / 340）保持不变 —— 加宽会直接挤占工作台中栏的图像预览面积。

### 字体族

| 用途 | 字体 | 理由 |
|---|---|---|
| 中文与通用标签 | **Noto Sans SC** | 开源可商用，字面清晰，12–13px 下辨识度优于系统黑体 |
| 西文 / 文件名 | **Inter** | 与 Noto Sans SC 的 x-height 匹配，中英混排不跳 |
| 技术数值 | **JetBrains Mono** | 等宽 + `tabular-nums`，数字宽度恒定 |

**必须用等宽字体的场景**（否则刷新时会左右跳动）：
显存与内存容量、tile 尺寸、耗时（ms / s）、节点数、参数量、模型体积、sha256、分辨率 `W × H`、放大倍数、`3 / 12 块` 进度、预估时间。

## 4. 间距体系（4pt 基准）

| Token | 值 | 典型用途 |
|---|---|---|
| `space-1` | 4 | 图标与文字之间 |
| `space-2` | 8 | 同组元素、按钮组内间距 |
| `space-3` | 12 | 表单项、顶栏子项 |
| `space-4` | 16 | 卡片内边距、栏内边距 |
| `space-5` | 24 | 页面左右边距（主工作台）、区块间距 |
| `space-6` | 32 | 独立页左右边距、页面头内边距 |

**惯例**：主工作台三栏用 16（紧凑），独立页用 32（舒展）。**同一页面内不混用两套边距**。

## 5. 圆角与阴影

| 元素 | 圆角 |
|---|---|
| 卡片 / 面板 / 大容器 | **8** |
| 卡片内次级容器、提示条 | **6** |
| 按钮 / 输入框 / 徽标 | **4** |
| 胶囊：筛选 chip / 状态徽标 / 开关 / 滑块把手 / 进度条 | **999** |

**阴影（仅两档，且仅在必要时用）**

| Token | 值 | 用途 |
|---|---|---|
| `shadow-card` | `0 4px 16px rgba(0,0,0,0.12)` | 浮层（下拉、Popover） |
| `shadow-elevated` | `0 8px 24px rgba(0,0,0,0.20)` | 模态、抽屉 |

> **常规卡片不使用阴影**——靠 `bg` 层级 + 1px 描边区分。深色界面里阴影几乎不可见，滥用只会增加渲染成本。

## 6. 主题机制

### 6.1 三态策略（对应 T-401 决策）

| 状态 | 行为 |
|---|---|
| **默认** | **深色**（`data-theme` 属性不设置或设为 `Dark`） |
| 手动切换 | 顶栏 `ThemeButton` 在 深色 / 浅色 之间切换 |
| 跟随系统 | 读取 `prefers-color-scheme`；用户手动切换后以手动值为准并持久化 |

### 6.2 实现约定

```ts
// 唯一主题入口，禁止在各页面散落判断
type ThemeMode = 'dark' | 'light' | 'system'

// 解析后统一落到 <html> 的 data-theme 属性上
document.documentElement.dataset.theme = resolved === 'light' ? 'Light' : 'Dark'
```

- **Element Plus 深色**：引入 `element-plus/theme-chalk/dark/css-vars.css`，在 `<html>` 上加 `dark` class；**同时**覆盖 `--el-color-primary` 为 `var(--Theme-primary)`，使组件库强调色与设计稿一致。
- **业务色只用 `tokens.css` 的变量**。Element Plus 自带的色板变量（`--el-color-primary-light-3` 等）只在其组件内部使用。
- **禁止**在页面里写 `if (isDark) { color: '#...' }` 这类分支——它会让主题切换漏掉一半元素。

### 6.3 浅色模式的三处特殊处理

浅色不是深色的机械反相，以下三处必须在浅色下单独验证：

1. **强调色加深**：`#0078D4` → `#0067C0`。原因是同一个蓝在白底上的对比度只有约 3.9:1，不满足 AA。
2. **语义色重取**：`success` / `warning` / `error` 在浅底上需更深的值（见 §2.4）。直接把深色版的浅绿/浅黄搬过来，在白底上几乎不可读。
3. **对比视图的背景**：中栏在深色下是 `bg-app`（近黑），浅色下是 `#F7F6F4`。图片是深是浅无法预知，因此**图片容器四周不要加任何描边或内阴影**，避免在浅色图片上出现"描边吃了一块图像"的观感。

## 7. 图标规范

- **全部为 SVG 描边图标**，不用图标字体、不用 emoji、不用 Unicode 符号。
- 统一描边宽度 **1.8**（16px 视口下），颜色统一 `#8A8A8A`。
  - 该灰在深色底上对比度 4.9:1、浅色底上 3.6:1，**两种主题共用同一个值**，无需为主题切换改图标颜色。
- 尺寸档位：**14**（表格与工具栏内）、**16**（顶栏、面板按钮）、**24**（上传区）、**32**（空态列表）、**48**（空态拖拽区）。
- 图标**不得独立承担语义**：所有图标按钮（主题切换、硬件、设置）必须带 `aria-label`，所有图标旁的信息必须有文字（如"进行中"而非只有一个色点）。

---

## 8. 动效约定

- **只做状态过渡，不做装饰动画**：悬停 120ms、面板展开 200ms、进度条宽度 300ms `ease-out`。
- **进度条不做无限循环动画**——推理进度是真实的、单调递增的，动画化会让"卡住"与"正在跑"无法区分。
- 骨架屏用于模型列表首次加载（PRD §6.2 明确要求）。
